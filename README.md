# ☕ Cafe Telegram Bot

Simple Telegram cafe bot made with Python and aiogram.

## 📌 Features

- `/start` — welcome message
- `/menu` — shows cafe menu
- `/order` — create an order
- Add products to cart
- Calculate total price
- Simple order system

---

## 🛠 Technologies

- Python 3
- aiogram 3
- asyncio
